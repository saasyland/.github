# SaaSy Land

A production-grade SaaS starter for [TanStack Start](https://tanstack.com/start) on Cloudflare Workers, with Better Auth on D1, Drizzle, Resend, Polar billing, nine languages and a test suite held at 100% coverage.

- **[saasyland.com](https://saasyland.com)** has the product, the [docs](https://saasyland.com/docs) and the [blog](https://saasyland.com/blog). Its source is public and MIT-licensed in **[saasyland/saasyland.com](https://github.com/saasyland/saasyland.com)**, and it runs on the stack the CLI generates.
- **The `saasyland` CLI** is on npm. Today it activates your licence (`npx saasyland@beta activate`). Project generation (`init`) arrives in a coming release.

Questions: [hello@saasyland.com](mailto:hello@saasyland.com). Security issues: follow the `SECURITY.md` of the repository concerned.
